Pink Trombone Demos

Articulatory speech synthesis, acoustic-landmark analysis, and synthetic dataset generation, built on Neil Thapen's Pink Trombone.

The three interactive modules below communicate via the BroadcastChannel API, so they must be open at the same time. Serve the repository with a local web server (e.g. npx live-server) and open each in its own tab:

  • TTS — type a word or phonemes; generates timed articulatory keyframes.
  • Pink Trombone — synthesizes audio and animates the vocal tract.
  • LEXI — waveform, spectrogram and acoustic landmarks; exports .wav + landmarks.json.

A headless batch generator drives these modules with Playwright to synthesize whole word lists into an audio + landmark dataset. See the README for full instructions.
